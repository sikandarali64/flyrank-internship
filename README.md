# FlyRank Internship

A 6-week internship portfolio repository documenting the frontend development work completed during the FlyRank program, including AI fundamentals, accessibility-focused frontend work, and full-stack project builds.

## Overview

This repository contains the learning and project work completed throughout the internship, with emphasis on:

- frontend engineering fundamentals
- form validation and accessibility
- AI prompting and workflow fundamentals
- full-stack app development
- portfolio-ready web projects

## Included Work

### 1. FL-02 Prompting Fundamentals

A learning module focused on prompt design and AI interaction techniques.

### 2. CV Analyzer

A Next.js-based project for analyzing CV/resume content.

### 3. HMS Pro Login Form Capstone

A polished login form project focused on user validation, accessibility, and responsive design.

### 4. MovieBox

A React + TypeScript movie search app with Firebase authentication and API integration.

### 5. ServiceIQ Pro

An AI-powered service dispatch platform developed for the hackathon-style capstone challenge.
